👁️ ما هو PIR Sensor؟

📌 التعريف:

PIR = Passive Infrared
حساس بيكشف الأشعة تحت الحمراء اللي بيطلعها جسم الإنسان 🔥

💡 الفكرة:

جسم الإنسان حرارته ≈ 37°م
بيطلع أشعة تحت الحمراء (مش بنشوفها)
الحساس بيكشف الأشعة دي ويقولنا: "في حركة!" 🚨

💻 أول كود - قراءة الحركة

🎯 الهدف:

نقرأ حالة الحساس ونعرضها على Serial Monitor

// تعريف الـ Pins int pirPin = 2; // PIR OUT في Pin 2 int ledPin = 8; // LED في Pin 8 // متغير للحالة int motionState = 0; void setup() { Serial.begin(9600); pinMode(pirPin, INPUT); pinMode(ledPin, OUTPUT); // استنى 30 ثانية عشان الحساس يجهز Serial.println("جاري تهيئة الحساس..."); delay(30000); Serial.println("الحساس جاهز!"); } void loop() { motionState = digitalRead(pirPin); if(motionState == HIGH) { Serial.println("🚨 في حركة!"); digitalWrite(ledPin, HIGH); } else { Serial.println("✅ مفيش حركة"); digitalWrite(ledPin, LOW); } delay(200); }

📖 شرح الكود

1

تعريف الـ Pins

pirPin = 2 → الحساس في Pin 2
ledPin = 8 → الـ LED في Pin 8

2

التهيئة (Calibration)

delay(30000) → استنى 30 ثانية
عشان الحساس يجهز ويضبط نفسه

3

قراءة الحالة

digitalRead(pirPin)
HIGH (1) = في حركة
LOW (0) = مفيش حركة

4

التحقق والتصرف

if(motionState == HIGH)
لو في حركة → شغل LED واعرض رسالة

✨ النتيجة: لما حد يتحرك قدام الحساس، الـ LED هيشتغل! 🚨

🚨 مشروع: نظام إنذار

🎯 الفكرة:

نعمل نظام إنذار يشتغل لما حد يدخل الغرفة!
LED + Buzzer (جرس) 🔊💡

int pirPin = 2; int ledPin = 8; int buzzerPin = 9; void setup() { pinMode(pirPin, INPUT); pinMode(ledPin, OUTPUT); pinMode(buzzerPin, OUTPUT); delay(30000); // تهيئة الحساس } void loop() { if(digitalRead(pirPin) == HIGH) { // إنذار! digitalWrite(ledPin, HIGH); tone(buzzerPin, 1000); // صوت 1000Hz delay(500); noTone(buzzerPin); delay(200); } else { digitalWrite(ledPin, LOW); } }

🎵 أوامر الصوت:

  • tone(pin, frequency) → شغل صوت
  • noTone(pin) → طفي الصوت

💡 مشروع: إضاءة أوتوماتيكية

🎯 الفكرة:

لمبة بتشتغل لوحدها لما حد يدخل!
وبتطفي بعد ما يمشي 🚶‍♂️💡

int pirPin = 2; int ledPin = 8; unsigned long lastMotion = 0; int lightTime = 5000; // 5 ثواني void setup() { pinMode(pirPin, INPUT); pinMode(ledPin, OUTPUT); delay(30000); } void loop() { if(digitalRead(pirPin) == HIGH) { digitalWrite(ledPin, HIGH); lastMotion = millis(); // سجل الوقت } // لو عدت 5 ثواني من آخر حركة if(millis() - lastMotion > lightTime) { digitalWrite(ledPin, LOW); } }

💡 ميزة:

بيوفر الكهرباء! 💰
زي اللمبة الذكية في البيت! 🏠

🔢 مشروع: عداد الزوار

🎯 الفكرة:

نعد كام مرة الحساس كشف حركة!
زي عداد الزوار في المحلات 🏪

int pirPin = 2; int count = 0; // عداد int lastState = LOW; // الحالة السابقة void setup() { Serial.begin(9600); pinMode(pirPin, INPUT); delay(30000); Serial.println("عداد الزوار جاهز!"); } void loop() { int currentState = digitalRead(pirPin); // لو الحالة اتغيرت من LOW لـ HIGH if(currentState == HIGH && lastState == LOW) { count++; Serial.print("عدد الزوار: "); Serial.println(count); delay(2000); // استنى عشان متعدش مرتين } lastState = currentState; }
